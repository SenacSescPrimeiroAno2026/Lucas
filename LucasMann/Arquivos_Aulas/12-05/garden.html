Grid Garden(Botão)

O que é?

O Grid Garden é um jogo educativo gratuito, desenvolvido pela Codepip, projetado para ensinar conceitos de CSS Grid Layout de forma divertida e interativa. O objetivo é escrever código CSS para regar um jardim de cenouras e eliminar ervas daninhas, passando por 28 níveis que aumentam de complexidade.
