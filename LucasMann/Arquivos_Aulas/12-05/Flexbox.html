Flexbox Froggy (Botão)

O que é?

O Flexbox Froggy é um jogo educativo gratuito e interativo projetado para ensinar os fundamentos do CSS Flexbox de maneira divertida. No jogo, você escreve código CSS para ajudar um sapinho e seus amigos a se alinharem sobre folhas (vitórias-régias), cobrindo 24 níveis com dificuldades progressivas.
