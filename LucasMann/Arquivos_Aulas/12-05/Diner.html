CSS Diner (Botão)

O que é?

O CSS Diner é um jogo interativo e educativo criado por Luke Pacholski para ensinar e praticar seletores CSS de forma divertida. Com 32 níveis, o jogo desafia os jogadores a escreverem seletores para "selecionar" elementos em uma mesa de jantar (elementos HTML), indo do básico ao avançado.
