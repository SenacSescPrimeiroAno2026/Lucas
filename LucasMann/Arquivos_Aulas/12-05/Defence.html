Flexbox Defense(Botão)

O que é?

O Flexbox Defense é um jogo educativo online baseado em navegador, no estilo tower defense, projetado para ensinar e praticar as propriedades do CSS Flexbox. O objetivo é posicionar torres de defesa, usando códigos CSS como justify-content e align-items, para impedir que inimigos atravessem o mapa.
